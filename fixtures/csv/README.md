# サンプル CSV

実際の VIRTUE / 電力会社の CSV フォーマットが確定するまでの検証用データ。
本システムは特定の列名に固定されていないため、これらはあくまで「よくある形の例」。

| ファイル | 想定 | 目的 |
| --- | --- | --- |
| `valid.csv` | 正常データ 10 行（UTF-8） | 通常の取込確認 |
| `duplicate.csv` | `valid.csv` と同じ契約番号を含む | 二重登録されないことの確認 |
| `errors.csv` | 10 行中 1 行がエラー | 正常 9 件 / エラー 1 件の切り分け確認 |
| `alt-columns.csv` | 列名がすべて異なる（英語・略称） | 列マッピングで吸収できることの確認 |
| `unknown-agency.csv` | 存在しない代理店を含む | 警告 / エラーの切り替え確認 |
| `sjis.csv` | Shift-JIS(CP932) エンコード | 文字コード自動判定の確認 |
| `evergreen-usage.csv` | 使用量・検針月・明細提出の有無つき | 階段表方式（エバーグリーン MPプラン）の確認 |

`valid.csv` の代理店コードはシードで作られる `AG-A` / `AG-B` / `AG-C` に対応している。
