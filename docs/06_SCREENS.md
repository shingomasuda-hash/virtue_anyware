# 06. 画面構成

## 6.1 レイアウト

```
┌──────────────────────────────────────────────────────┐
│ Header: 組織名 / 期間セレクタ / 検索 / 通知 / ユーザーメニュー │
├────────────┬─────────────────────────────────────────┤
│ Sidebar    │ Main content                             │
│ (240px)    │  ┌ Page header: 見出し + 主要アクション ┐ │
│ セクション  │  ├ KPI row (数値は等幅・tabular-nums)  ┤ │
│ 見出し付き  │  ├ Filter bar                          ┤ │
│            │  └ Table / Chart                       ┘ │
└────────────┴─────────────────────────────────────────┘
```

デザイン指針（§29）: Stripe / Linear / freee 系。
余白は 4px グリッド、角丸は 6px まで、グラデーション不使用、
影は `0 1px 2px rgba(0,0,0,.06)` 程度、罫線で情報を区切る、数値は `tabular-nums` 右寄せ、
1画面の情報密度は高く保ちつつ、見出し・区切り線・色の意味付け（緑=良/赤=悪）で可読性を確保。
