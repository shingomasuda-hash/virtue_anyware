## 13.2 検出した問題と対応

### F-1 【重大】書き込み経路が存在しなかった

PHASE 1 の画面はすべて閲覧専用で、**Server Action が 1 つも実装されていなかった**。
顧客登録・契約登録・代理店作成が UI から実行できず、
「API / Server Action でも認可されているか」は検証対象すら存在しない状態だった。

`grep -rl "'use server'" src` → 0 件
`createAgency` / `updateAgency` の参照 → 0 箇所（デッドコード）

**対応**

- `src/server/actions/run.ts` を追加。全 Server Action が
  「認証 → 認可 → Zod 検証 → 例外正規化」を必ず通る構造にした。
- 書き込みサービスを追加:
  `services/customers.ts` / `services/contract-write.ts` / `services/agencies.ts`
- Server Action と画面を追加:
  顧客 登録/編集、契約 登録/編集/キャンセル/単価再適用、代理店 登録/編集、代理店単価 追加
- `agency.repo.ts` にあった重複実装（未使用の createAgency/updateAgency）を削除した。

### F-2 【重大】単価スナップショットが本番経路から呼ばれていなかった

`priceContract` / `applyPricingSnapshot` は実装・テスト済みだったが、
**呼び出し元が 0 箇所**だった。シードは独自に `watt * 150` と手計算しており、
本番経路と計算方法が二重化していた（乖離に気づけない状態）。

**対応**

- 契約の作成・更新は必ず `createContract` / `updateContract` を通り、
  そこで `priceContract` → スナップショット保存 → `contract_pricing_snapshots` 記録を行う。
- シードも `priceContract` を使うように変更した。結果の金額は変わらず（750,000 / 500,000 / 250,000）、
  さらに適用した単価ルール ID が 30/30 件で記録されるようになった。

### F-3 【重大】監査ログが 1 件も記録されていなかった

`audit_logs` テーブルと `recordAudit()` は存在したが、呼び出し元が 0 箇所。
`SELECT count(*) FROM audit_logs` → **0**。

**対応**

- 顧客更新/削除、契約作成/更新/キャンセル/単価再適用、代理店作成/更新、単価追加、
  CSV 取込確定/ロールバックで `recordAudit` を呼ぶようにした。
- 財務データ変更は変更前後の値を保存する（§27）。
- 監査ログ閲覧画面 `/settings/audit` を追加し、変化したキーだけを差分表示する。

### F-4 【中】代理店取得で ID がスコープを上書きしていた（PHASE 1 中に検出・修正済み）

`findAgencyById` が `{ ...scopeWhere(ctx), id }` と書かれており、
代理店ロールのスコープに含まれる `id`（= 自代理店）を、要求された `id` が**上書き**していた。
統合テストで検出し、`{ AND: [scope, { id }] }` に修正済み。

### F-5 【中】単価解決が非決定的だった

`agency_unit_prices` に適用開始日が同じ行が複数あると、
`orderBy: effectiveFrom desc` だけでは順序が決まらず、解決結果が実行ごとに変わりうる状態だった。
書き込み経路のテスト追加時に検出。

**対応** — `orderBy: [{ effectiveFrom: 'desc' }, { createdAt: 'desc' }]` とし、
「適用開始日が同じなら後から登録されたものを採用する」を明文化した。

### F-6 【軽】`event_metrics` の NULL 複合ユニーク

`@@unique([eventId, boothId, metricDate, hourSlot])` は NULL を含むと
PostgreSQL 上で一意性を強制できない。シードで検出済み、`ASSUMPTIONS.md B-8` に記録。
アプリ側で存在確認してから作成する運用とした。

## 13.3 計算検証（DB 実データ）

```sql
select "contractNumber", "contractWatt", "hqUnitPrice", "agencyUnitPrice",
       "hqRevenue", "agencyPayout", "hqGrossProfit", round("grossMargin"*100,2)
from contracts where "contractWatt" = 5000;
```

| AG-A-00002 | 5,000 | 150.0000 | 100.0000 | **750,000** | **500,000** | **250,000** | 33.33% |
| CSV-0001 | 5,000 | 150.0000 | 100.0000 | **750,000** | **500,000** | **250,000** | 33.33% |
