# サンプル CSV

実際の VIRTUE / 電力会社の CSV フォーマットが確定するまでの検証用データ。
本システムは特定の列名に固定されていないため、これらはあくまで「よくある形の例」。

| ファイル | 想定 | 目的 |
| --- | --- | --- |
| `valid.csv` | 正常データ 10 行（UTF-8） | 通常の取込確認 |
| `duplicate.csv` | `valid.csv` と同じ契約番号を含む | 二重登録されないことの確認 |
| `errors.csv` | 10 行中 1 行がエラー | 正常 9 件 / エラー 1 件の切り分け確認 |
| `alt-columns.csv` | 列名がすべて異なる（英語・略称） | 列マッピングで吸収できることの確認 |
| `unknown-agency.csv` | 存在しない代理店を含む | 警告 / エラーの切り替え確認 |
| `sjis.csv` | Shift-JIS(CP932) エンコード | 文字コード自動判定の確認 |
| `evergreen-usage.csv` | 使用量・検針月・明細提出の有無つき | 階段表方式（エバーグリーン MPプラン）の確認 |
| `electricity-real-format.csv` | **実運用の電力 CSV と同じ 32 列**（値はダミー） | 実ファイルの列名・重複列・「直営」・単位付き検針月を吸収できることの確認 |

`valid.csv` の代理店コードはシードで作られる `AG-A` / `AG-B` / `AG-C` に対応している。

## `electricity-real-format.csv`

現場で使われている実ファイルの**列名・列順・列構成をそのまま再現**し、
値だけを架空のダミーに置き換えたもの（実在の顧客情報は含まない）。
詳細は `docs/07_CSV_IMPORT.md` 7.14。

| 行 | 確認したいこと |
| --- | --- |
| 1 | 代理店名が「直営」→ 本部直販（`agency_id = NULL`）として取り込まれ、代理店未登録エラーにならない |
| 2 | 「別途」が 2 列あっても両方の値が残る（`別途` / `別途 (2)`） |
| 3 | 存在しない代理店 → 従来どおりエラー |
| 4 | 固定電話番号が空でも携帯番号を主電話として補完する |

**契約ステータスの列が無いため、取込オプションで既定ステータスの指定が必須**。
`相対割引` / `直営粗利` / `別途` / `粗利` / `別途 (2)` / `ポイント` の 6 列は
意味が未確定のため意図的に未マッピング（取り込まずに無視する）。
